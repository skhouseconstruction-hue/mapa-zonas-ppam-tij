Cómo usar el mapa

1. Agrega una zona

Pulsa “Agregar zona”, mueve el pin al lugar exacto y confirma la ubicación.

2. Completa su ficha

Escribe el nombre, una descripción y agrega una fotografía.

3. Consulta las zonas

Todas las zonas aparecerán en la pestaña Zonas.

Resguardo de exhibidores

Registra el lugar, dirección automática al colocar el pin rosa, fotografía y contacto responsable. Los registros se administran por separado de las zonas.

4. Cómo llegar

Abre Google Maps para navegar hasta la zona seleccionada.

Los datos se guardan en este navegador. Exporta una copia de seguridad para conservarlos o trasladarlos.

Conectar Google Maps

Para mostrar el mapa real necesitas una clave de Google Maps Platform. Pégala aquí; se guardará en este navegador para el administrador.

No compartas esta clave públicamente. Antes de publicar, limita su uso al dominio de tu aplicación y a Maps JavaScript API.
