# Mapa de zonas PPAM-TIJ

Alojamiento del mapa personalizado para incorporarlo en SAFI mediante un iframe.

URL prevista de GitHub Pages:
https://skhouseconstruction-hue.github.io/mapa-zonas-ppam-tij/

El archivo público del mapa se publicará como index.html. El administrador y los datos de trabajo se mantienen separados del mapa público.

Flujo de actualización:
1. Agregar, editar o eliminar zonas en el administrador.
2. Generar el HTML público con las zonas y fotografías actualizadas.
3. Reemplazar index.html en este repositorio.
4. Mantener la misma URL para SAFI.

Pendiente: subir el HTML público generado desde el administrador con las ubicaciones y fotografías definitivas.
